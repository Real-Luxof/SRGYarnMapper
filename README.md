# SRGYarnMapper
A teeny tiny little tool to automatically grab SRG, Intermediary, Yarn, and Mojmap mappings for a Minecraft version of your choice, and then generate SRG -> Yarn and Mojmap -> Yarn editions of them.  

I just made this for a project or two I'm working on, but I've found I probably don't need this. Still, it's made, no matter how bad it is, so I've uploaded it to GitHub.
